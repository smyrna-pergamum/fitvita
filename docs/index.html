That was the warm-up. The app counts real steps, glasses and breaths — and keeps it all on your phone.

How do I install it?

The download link opens the APK file from the GitHub release. Open it on your Android phone and follow the installer. If asked, allow installs from this source for your browser. FitVita supports Android 8.0 and newer.

Do I need the internet?

Exercises and all local tracking work offline. Map tiles, radio search and internet radio streams need a connection.

Is it paid? Do I need an account?

FitVita is free and open source under GPL-3.0-or-later. No account needed — read the source code on GitHub.
